A historical sample: a small change to a sample project on October 15, 2026, at Quarterback commit 3fc08fd. Each panel is an excerpt from that run’s record. A run on the current version will replace it after the next rehearsal.

  1. Step 1

    Describe the change

    A plain-language request. The project showed 30 seconds as 0m 30s.

  2. Step 2

    Approve the requirements

    Two checks that must pass and the one file that may change. A local model drafted the list; a person edited and approved it.

  3. Step 3

    Quarterback checks the change

    Claude Code made the change in an isolated workspace. Quarterback then ran the project’s tests and both checks on it.

  4. Step 4

    Review the patch

    The change comes back as a proposed patch. Nothing touches your project until you apply it.

Progress · November 18, 2026

Where Quarterback stands.

Research milestone

A fair side-by-side comparison now runs end to end

  • On one task we had already worked on, Claude Code alone and Claude Code with Quarterback both solved it, checked by an independent grader. Run
  • This shows the comparison works. It does not show that Quarterback helps or saves cost. The checklist was written by a model and reviewed by an AI reviewer. Details

Known limitation

Automatic checklist drafting is not reliable yet

  • A diagnostic of our older drafting method, which writes the whole checklist in one model reply: its latest test request was still blocked after about 334 seconds. Today a person writes or reviews the checklist before a run. Measurements

Next

One supervised rehearsal completed

  • On a Mac, with a checklist a person wrote and reviewed: verified on the first attempt in 136 seconds. Setup was assisted and the sandbox was already installed. Evidence
  • One run, not a reliability rate. Self-service beta is not ready.
  • Research on new tasks is paused while we do this. Evaluation notes
