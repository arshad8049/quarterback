Supported setup

What you need today.

Quarterback is deliberately narrow while it’s being tested. Anything not listed here isn’t supported yet.

AI assistant
Claude Code only, used with your own Claude subscription or Anthropic API key.
Projects
JavaScript or Node.js projects whose tests use Node’s built-in test runner (node:test).
Computer
Ubuntu 24.04 on a standard 64-bit (x86_64) machine with Docker and 16 GB of memory is the validated setup. macOS: limited successful runs; not a validated supported environment. Windows: not supported.
Also installed
Node.js 20 or newer, git, and Ollama with a small local model that Quarterback uses for its own steps.
Your code
During a run, the task and the code Claude Code reads are sent to Anthropic under your account. Quarterback’s own model calls stay on your machine by default. Data and privacy
