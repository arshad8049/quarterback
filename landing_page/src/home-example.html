What a check result can be

Pass
Every agreed check and the project’s tests passed.
Fail
A check or test failed, or a file that was off-limits was changed.
Partial
Some checks couldn’t be decided.
Unresolved
The evidence couldn’t settle it, for example a requirement with no runnable check.

How a run can end

Verified
The change was checked and passed.
Failed / Unresolved
The change was checked, and the result was a fail or couldn’t be settled.
Blocked
The run stopped before checking anything, for example because the requirements weren’t approved or a project dependency was refused. It says nothing about whether a change would have passed.
Error / Cancelled
The run itself broke (such as a timeout or running out of memory) or was stopped.
