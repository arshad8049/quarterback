# KAN-110 field dictionary

Generated by `node public/dictionary.mjs` from `field-policy.mjs`. Do not edit by hand.

Every source column belongs to exactly one store:

| Store | Who sees it |
|---|---|
| **agent** | Both arms (the agent packet), after leak redaction. |
| **controller** | The run controller only: sets up the clean base repository and environment. |
| **vault** | The grader only: reference solution, hidden tests, test lists, grading commands. |
| **quarantine** | Nobody during a run: hints, solution size/shape, difficulty labels from historical model results, answer-bearing IDs kept for provenance. |

A column that is not listed here is quarantined automatically.
